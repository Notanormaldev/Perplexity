# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ZErio AI, please do **NOT** open a public GitHub issue.

Instead, report it privately via either of these emails:

📧 **Primary:**  harshpatel20050@gmail.com 
📧 **Alternate:** hellozerio.ai@gmail.com


Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
